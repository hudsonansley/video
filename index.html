How this keeps files from bloating
Cutting, copying, pasting, reversing, and reordering never touch pixel data — they only rearrange references to frames in your original files. The only time video is actually re-encoded is once, when you export, and the encoder is set to match your source's own bitrate and resolution by default (editable above) using the efficient VP9/VP8 codec, so a round trip through this editor doesn't inflate file size the way repeated re-encodes in a typical NLE can. Export runs in real time (it plays through your timeline once while capturing), and the current build handles picture only — audio tracks are not yet carried into the export.
